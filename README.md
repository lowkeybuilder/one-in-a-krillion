# One in a Krillion

A non-AI helper for the browser game **One in a Krillion**.

### Features
- Automatic screen scanning
- OCR question detection
- Local answer database
- Finds niche answers
- Suggests what to type

### Requirements
- Python
- MSS, Pillow and pytesseract
- Tesseract OCR

### Installation
See `requirements.txt` for Python dependencies.
